Olist Sales Performance Dashboard
Project Overview
This project presents an interactive sales performance dashboard built in Power BI using the public Olist Brazilian E Commerce dataset. The dashboard provides a clear view of sales performance by tracking revenue, orders, customers, payment methods, and product performance through interactive visualizations.
About the Dataset
The Olist Brazilian E Commerce dataset is a public dataset containing information on customers, orders, products, sellers, payments, and reviews. It provides a realistic business scenario for analyzing sales performance and customer activity.
Business Objective
The goal of this project is to monitor key business metrics in one place, making it easier to identify sales trends, compare performance, and support business decisions.
Data Cleaning & Transformation
The dataset was prepared in Power Query by correcting data types, removing duplicate records, and creating the data model required for analysis. DAX measures were created to calculate the key performance indicators used in the dashboard.

Key Performance Indicators
•	Total Revenue

•	Total Customers

Analysis Questions
•	How much revenue was generated?
•	How many orders and customers were recorded?
•	How did revenue change over time?
•	Which product categories generated the highest revenue?
•	Which payment methods were used most?
•	Which states had the highest number of customers?
Key Findings
•	Revenue trends make it easy to identify changes in sales performance over time.
•	Customer activity varies across different states.
•	Payment preferences differ across customers.
•	Product categories contribute differently to overall revenue.
