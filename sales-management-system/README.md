# Sales Management System

## Overview

This project is an Excel based sales management system designed to record sales transactions and maintain a structured sales database.

## Business Problem

The system is designed to make sales recording easier and keep transaction records organized.

The system focuses on:

- Recording sales transactions
- Organizing sales records
- Reducing manual data entry
- Maintaining a structured database

## Workbook Structure

### Entry

The main data entry sheet containing:

- Date
- Customer
- Product
- Quantity
- Unit Price
- Discount
- Payment Method
- Total

### Database

Contains the recorded sales transactions in a structured Excel Table.

## Approach

The workbook was structured using Excel Tables, VBA, Data Validation, formulas.

VBA was used to save transactions from the Entry sheet directly into the Database.

## Key Features

- Structured sales database
- VBA transaction entry
- Data Validation
- Automatic transaction recording
- Automatic calculations

## Tools

**Microsoft Excel | VBA | Excel Tables | Data Validation | Excel Formulas**
