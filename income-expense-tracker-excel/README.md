# Income & Expense Tracker

## Overview

This project is an Excel based income and expense tracker designed to record financial transactions, organise categories, and provide a clear monthly overview of income and expenditure.

## Business Problem

The tracker is designed to make it easier to record financial activity and understand where money is coming from and where it is being spent.

The tracker focuses on:

* Recording income and expenditure consistently
* Organising transactions by category
* Automatically calculating category totals
* Providing a monthly financial overview

## Workbook Structure

### Setup

Contains predefined Income and Expenditure categories used throughout the tracker.

### Transactions

The main data entry sheet containing:

* Date
* Type
* Category
* Amount
* Month
* Description

Dropdown lists are used for Type and Category to maintain consistent entries.

### Monthly Overview

Summarises income and expenditure by category using Excel formulas and provides a clear view of monthly financial activity.

## Approach

The workbook was structured using Excel Tables and Data Validation dropdowns.

SUMIF formulas were used to automatically calculate category totals from the transaction data.

The worksheets were formatted with gridlines removed, controlled borders, and unused rows and columns hidden to create a clean and focused interface.
